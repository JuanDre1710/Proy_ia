# Diccionario de variables categóricas codificadas

En este archivo se explican las variables que tienen valores codificados como 0, 1, 2, etc. para facilitar el entendimiento y la interpretación del modelo IA.

---

### 🔹 `tipo_siniestro`
- `0`: Robo
- `1`: Choque
- `2`: Incendio

### 🔹 `tipo_bien`
- `0`: Auto
- `1`: Inmueble
- `2`: Equipo

### 🔹 `estado_bien`
- `0`: Nuevo
- `1`: Usado
- `2`: Obsoleto

### 🔹 `uso_bien`
- `0`: Particular
- `1`: Comercial

### 🔹 `estado_siniestro`
- `0`: Pendiente
- `1`: Pagado
- `2`: Rechazado

### 🔹 `tipo_proveedor`
- `0`: Taller
- `1`: Médico

### 🔹 `tipo_cliente`
- `0`: Persona
- `1`: Empresa

---

**📝 Notas:**
- Estas codificaciones permiten que la IA las interprete como categorías en lugar de texto.
- Si querés agregar más categorías o cambiarlas, recordá actualizar este archivo para mantenerlo consistente.
